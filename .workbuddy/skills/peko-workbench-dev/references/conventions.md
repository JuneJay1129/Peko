# Peko 编码约定

工作台（DeskCraft / 小台）与桌面端的既有规范，改动时严格遵守。

## 工作台页面规范

- 零依赖、单文件 HTML，所有 CSS/JS 内联，不引外部库/CDN。
- 亮色主题（light theme）。
- 图标一律 SVG，禁用 emoji。
- 字体用系统字体栈（system font stack）。
- UI 文案用简体中文。
- 「今天要处理」置顶。
- 提供示例/种子数据，开箱即用。
- 导出 / 导入 / 清空（清空需二次确认）；条目 ≥30 时给温和备份提示。
- 每个工作台聚焦 3–4 个模块为宜（当前已扩到 6 个，新增前先评估是否该拆）。

## 代码维护原则

- 修调用方 / 任务侧，不改公共 Utils，避免影响其他调用方。
- 数据写入必须经 `plans_store` / `workbench_server`，不绕过、不直接改 `data/*.json`。

## 沟通 / 文档偏好（项目所有者）

- 偏好中文沟通。
- 决策辅助偏好结构化表格与清晰对比。
- 文档偏好完整、全链路的技术说明（覆盖完整流程的 markdown），而非简略摘要。
- 向非开发人员讲解时偏好流程图，并可用 /caveman 原始人白话风格。

## 金融/股票可视化（如涉及）

- 中国A股惯例：涨=红、跌=绿（与欧美相反），默认货币符号 ¥。
