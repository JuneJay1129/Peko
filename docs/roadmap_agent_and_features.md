# Peko 功能与 Tool 扩展建议

本文档整理当前 AI 桌宠（Peko）的后续优化方向，供开发排期参考。

## 当前能力概览

- **桌宠本体**：多宠物、动画、情绪（心情/饱食度/精力）、操控模式、分身模式、托盘菜单
- **对话**：小输入框气泡 + 大聊天窗口（多轮记忆、历史持久化）
- **Agent**：`AgentLoop` 轻量工具调用循环（最多 3 轮）
- **已有 Tool**：`web_search`、`get_weather`、`read_file`、`summarize_file`

---

## 一、优先增加的 Tool

| Tool | 作用 | 优先级说明 |
|------|------|------------|
| `get_datetime` | 返回当前日期、时间、星期 | 零依赖，实现成本低 |
| `set_reminder` / `list_reminders` | 本地提醒（托盘通知 + 宠物气泡） | 桌宠天然适合「陪你、提醒你」 |
| `clipboard_read` | 读取剪贴板文字 | 与 `summarize_file` 互补，适合「总结刚复制的内容」 |
| `open_url` | 打开网页或本地路径 | 配合 `web_search` 搜索结果 |
| `list_dir` | 列出目录文件 | 比直接 `read_file` 更符合自然对话 |
| `write_file` | 在允许目录写入笔记/备忘 | 与读文件成对，可保存摘要、待办 |
| `system_info` | CPU/内存/电量等（需权限） | 实用向查询 |
| `translate` | 翻译文本 | 陪读、陪写场景常见 |

**建议首批实现**：`get_datetime`、`set_reminder`、`clipboard_read`。

---

## 二、与「桌宠」强绑定的功能

### 1. 情绪 ↔ 行为联动

已有心情/饱食度/精力，可进一步：

- 饿了主动说「想吃东西」，并可触发 `web_search` 搜美食
- 心情低时切换 `sulk` / `cry` 等动画，对话语气同步变化
- 久未互动时主动搭讪（结合本地提醒）

### 2. 主动陪伴

- 定时问候（早上好、午休、下班）
- 番茄钟：专注期间宠物安静，结束跳出来鼓励
- 久坐提醒：每小时提示活动

### 3. 对话体验优化

- 大聊天窗口支持**流式逐字显示**（小气泡已有，大窗口待完善）
- 工具调用结果格式化展示（天气卡片、文件摘要折叠块）
- 对话历史按宠物隔离（当前 `data/chat_history` 为全局）

## 三、中等投入、长期价值高的 Tool

| Tool | 典型场景 |
|------|----------|
| `screenshot` / `ocr` | 「这张截图写了什么」「帮看屏幕报错」 |
| `run_command`（白名单） | 开发者向：查 git 状态、跑测试（需严格沙箱） |
| `calendar` | 读取本地日历 / Outlook |
| `note_search` | 搜索用户此前让宠物记下的笔记 |
| `pet_action` | LLM 触发宠物动作，如 `play_animation("wave")` |

其中 `pet_action` 可让 Agent 不仅「说」，还能「动起来」，显著增强桌宠沉浸感。

---

## 四、架构层面建议

1. **Tool 注册配置化**：在 `pet_config.json` 的 `slots` 中声明每宠物可用工具（陪伴型 vs 工具型宠物分化）
2. **长期记忆**：将用户偏好、名字、常去城市写入 `data/memory.json`，注入 system prompt
3. **Tool 结果缓存**：天气、搜索等短时复用，减少 API 调用
4. **错误可感知**：工具失败时用宠物人设语气解释，而非生硬报错

---

## 五、推荐实施顺序（若只做 3 项）

1. **`set_reminder` + 托盘通知** — 从「能聊」升级为「能帮忙」
2. **大聊天流式输出** — 直接改善核心对话体验
3. **`pet_action` tool** — 强化 AI 与桌宠动画的联动

---

## 六、方向选择参考

| 方向 | 侧重点 | 代表功能 |
|------|--------|----------|
| 实用助手 | 效率、工具 | 提醒、文件、剪贴板、日历 |
| 情感陪伴 | 人设、互动 | 情绪联动、主动对话、番茄钟 |
| 极客向 | 开发、系统 | 截图 OCR、命令执行、目录浏览 |

可根据产品定位择一为主、其余为辅，避免功能堆砌导致桌宠特色被稀释。
