# 键鼠造型重构方案

三条诉求：**不要胳膊**、**键盘和鼠标翻 180°**、**宠物 + 键盘 + 鼠标整体倾斜**。
三条都改完之后，造型剩下的"不好看"主要不是这三点造成的，而是**没有落地阴影、明度分层不够**——所以第五节的细节一起做，否则改完还是像贴纸。

---

## 二、目标形态

俯视桌面一张：**鼠标垫 + 鼠标在左，小键盘在右，猫在中间**，三样共用同一个 8° 倾斜和同一套明暗；没有手臂，爪子直接搭在键帽 / 鼠标上，靠接触阴影贴住。

```
        ┌─ 画布 420×280（整体绕 (210,228) 顺时针 8°）
        │
        │      ╭──────────╮
        │      │   猫头   │          ← body.svg 跟着转
        │      ╰──────────╯
        │  ▱▱▱▱  ╱▱▱▱▱▱▱▱  ← 键盘（Tab 行在近边）
        │ ▭鼠标 ▱▱▱▱▱▱▱▱▱▱
        └───────────────────────────
```

关键判据：**远边窄、近边宽**（单应投影已烘进素材）、**近端在前**（Tab 行靠观众）、
**三样东西的灭点一致**（键盘、鼠标、垫子三条远边延长线应交于同一点附近）。

---

## 三、步骤 1：去掉手臂

改动极小，但要去掉"胳膊一断手就飘"的副作用。

1. `peko/core/bongo_modes.py` 的 `mouse` 条目：`draw_arms=False`（`arms` 造型仍在用，渲染层代码不动）。
2. `shoulders` 字段在 mouse 条目里删掉（留着也是死数据），`mouse_hand="l"` 保留。
3. **补接触阴影**，否则手是贴在键帽上的贴纸：在 `gen_bongo_mouse.py` 的 `_paw()` 里先画一层
   `ellipse(cx, cy+1.6, rx*0.96, ry*0.9) fill="#000" opacity="0.08"`，再画爪本体。
   键盘 / 鼠标本体同理（见第五节第 2 条）。
4. `paint_arms()` 里的 `if not self.draw_arms: return` 已经存在，不用改。

**验收**：渲染后键区上方没有灰色管子；`renderer.draw_arms is False`；`paint_arms` 不产生任何绘制。

## 四、步骤 2：键盘和鼠标翻 180°

### 4.1 键盘

`gen_bongo_mouse.py:176-177` 现在是：

```python
u0, u1 = x / COLS, (x + w) / COLS
v0, v1 = row / ROWS, (row + 1.0) / ROWS
```

改成绕键帽区中心镜像（和 60% 第 133-134 行同一个语义，但在 **uv 空间**做，透视会自动跟随）：

```python
u0, u1 = (COLS - x - w) / COLS, (COLS - x) / COLS
v0, v1 = (ROWS - row - 1.0) / ROWS, (ROWS - row) / ROWS
```

两点注意：

- **键帽厚度方向不能跟着翻**。`side` 仍然是 `y + 1.4`（朝画面下方 = 近端），翻转只改键位不键帽朝向；旋转后近排仍在下方，所以不用动。
- `h{cap}` 高亮是从 `face` 算出来的，自动跟着走，不用单独处理。
- `PAW_REST` 不用改（爪子休息位是画面坐标，与键位朝向无关）。

### 4.2 鼠标

鼠标分两个方案，建议 B：

**A（最小改动）**：四边形不动，只翻内部 uv。按键从远端翻到近端：
`KEY_BAND = (0.62, 1.0)`，中缝 `v 0.04→0.36` 改成 `0.64→0.96`，滚轮 `v=0.26` 改 `0.74`，
左右键 `u` 区间互换。改完是个"头朝左、按键朝观众"的横放鼠标——比现在好，但长轴方向还是错的。

**B（推荐）**：长轴竖起来，头朝远端。换掉四边形：

```python
# 44×72，头窄尾宽（远端更小），头朝右上（屏幕方向）
MOUSE_QUAD = ((58.0, 190.0), (102.0, 196.0), (116.0, 252.0), (64.0, 260.0))
KEY_BAND = (0.06, 0.40)     # 按键只占远端 40%，下半截被手压住
```

于是：左右键 `u` 分别 `[0.06, 0.44]` / `[0.56, 0.94]`、`v` 取 `KEY_BAND`；
滚轮椭圆在 `(0.5, 0.30)`；中缝线 `v 0.04 → 0.40`。
`PAD_QUAD` 不动（142×76 装得下 52×70 的鼠标）。
`HAND_CX/HAND_CY` 移到鼠标 `v≈0.62` 处（约 `88, 232`），继续压住下半截。

> 鼠标指向如果反了（要头朝近端），把 `MOUSE_QUAD` 的 v 顺序对调即可，其余常量不用改——方案里先按"头朝远端"落。

**验收**：Tab 行在近边（画面下方）、空格行在远边；按 `q` 高亮落在**左近**角；鼠标左右键靠观众一侧，滚轮在按键下方中线。

## 五、步骤 3：整体倾斜 8°

渲染层**不需要改代码**——`paint_pad()` 里 `_tilted()` 一次包住 `table + pad + mouse`，
`paint_desk()` 走 `_desk_matrix()`（`persp * tilt`），`_paint_body_layer()` 也走 `_tilted()`。
`persp_inset=0` 时 `_persp()` 是恒等，所以 `_desk_matrix()` 退化为纯 8° 旋转。

要改的只有数据和素材边界：

1. `bongo_modes.py` mouse 条目：`tilt_deg=8.0`、`tilt_cy=228.0`（与 60% 同参）。
2. **`table` 必须外扩**。现在 `TABLE_EDGE=((0,126),(420,168))`，绕 (210,228) 转 8° 后左上角跑到
   `(16.2, 97.8)`、右上角 `(426.3, 197.8)`——画布左上和右上直接露透明。
   改成覆盖 `(-60,-80) → (480,340)` 的大四边形（四角都出画），转完仍然铺满。
3. **`pad` 左沿外扩**到 `x=-16`，保持"垫子切出画布"的观感（转完原 x=0 会退到 7.9）。
4. 旋转后关键点校验（顺时针 8°，中心 (210,228)）：

| 点 | 原坐标 | 旋转后 | 结论 |
|---|---|---|---|
| 键盘 右下 | (400,232) | (397.6,258.4) | 距底边 21.6，安全 |
| 键盘 右上 | (336,164) | (343.7,182.1) | 距右边 76，安全 |
| 键盘 左下 | (202,252) | (198.7,250.7) | 安全 |
| 鼠标 右端 | (130,246) | (128.3,234.7) | 安全 |
| 垫子 右下 | (120,262) | (116.2,249.2) | 安全 |
| 桌面 左上 | (0,126) | (16.2,97.8) | **出画→必须外扩** |
| 猫头 右上 | (278,78) | (298.2,89.0) | 安全，头顶不会被切 |
| 鼠标手 中心 | (88,232) | (88.6,215.0) | 随转，`mouse_center()` 自动跟上 |

**验收**：四角无透明；换到 `paws` 再换回来，宠物姿态连续（不再"坐正"）；
`mouse_center()` 与渲染出的爪子中心一致（±0.5px）。

## 六、顺带修的造型细节（P1）

1. **明度分层**（相邻至少差 8%）：桌面 `#F3E8D8`、键帽 `#FFFDF7`、外壳 `#E7D5BE`、垫子 `#D6C5AE`。
2. **落地阴影**：素材里加 `#kb_shadow` / `#mouse_shadow`，`fill="#000" opacity="0.07"`，
   整体偏移 `(2,4)`，画在 `desk` / `mouse` **之前**。
3. **外壳只留一层**：删掉 `1.022/1.048` 的内壳路径，外壳外扩从 7 收到 4.5。
4. **键缝按行补偿**：`gap = 1.3 * (1 + 0.4 * (row + 0.5) / ROWS)`，远排细近排粗，透视下宽度才一致。
5. **爪子落点**：`Y_OFFSET` 从 `-5` 收到 `-2`（40% 键帽只有 15 高），否则高亮全被盖住。
6. **Enter 粉**：40% 布局里把 `enter` 的 kind 改成 `func`，或把 `#F2A6BC` 调成 `#F0B7C4`。

## 八、验收标准

- `python scripts/gen_bongo_mouse.py` 输出 40 keys，`bongo_mouse.svg` 里 `h*` 元素 40 个。
- 全量单测通过（当前 176 + 新增 ≥4 条）；`BongoRenderer(mode='mouse')` 的
  `_desk_matrix()` 不再是纯倾斜（旋转角 8°）、`draw_arms is False`。
- 三张离屏渲染目视：静止态（双手休息位）、打字态（`q` + `space` + 鼠标左键）、切模式前后。
- 切 `paws ↔ mouse` 时窗口尺寸不变（361×240），宠物姿态不跳。

## 九、风险

1. **键盘翻 180° 后近排贴底**：近排转完 y≈258，爪子半径 10 → 268，画布 280，
   只剩 12px 余量。若后面再加阴影，得把 `KB_QUAD` 整体上抬 4~6。
2. **鼠标竖放后比例**：52×70 在 142×76 的垫子上偏长，容易看成"立在垫子上的胶囊"，
   生成后要对着渲染图调 `rx` 圆角和 `v` 向压缩。
3. **`tilt` 与 `persp` 的复合**：mouse 造型的透视烘在坐标里，`persp_inset` 必须保持 0；
   哪天有人给 mouse 加上 `persp_inset`，键盘会被二次收窄、爪子落点集体偏移。
4. **`test_bongo_layout.py` 的默认模式**：测试已写死 `mode=paws`，新增 mouse 用例必须显式传
   `mode=get_mode("mouse")`，否则会读 `config/bongo.json` 里用户的选择而随机红。
