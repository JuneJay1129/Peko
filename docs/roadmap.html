生产力工具

take_notes / recall_notes
工作量·低

将用户说的内容写入本地 Markdown 笔记文件，或检索历史笔记

在 data/notes.md 中追加 / 检索内容；支持按关键词召回。复用现有 file_utils 路径管理逻辑。

示例：「帮我记住：明天买牛奶」→ 追加到笔记；「我上次说要买什么？」→ 关键词检索返回
todo_manager
工作量·中

管理简单待办列表，持久化到本地 JSON

支持 add / list / done / clear 操作；以 data/todos.json 存储；LLM 可根据对话上下文自动调用。

示例：「加个待办：整理文档」「列一下我的待办」「把第一个标记完成」
pomodoro（番茄钟）
工作量·中

番茄钟管理：专注 25 分钟 + 休息 5 分钟，完全复用现有 set_timer + 倒计时显示

封装 set_timer；自动在专注结束后再设置一个休息提醒。宠物可在专注期间切换为专注状态动画（若有）。

示例：「开始一个番茄钟」→ 25min 专注 → 提醒休息 → 5min 休息 → 循环

系统集成工具

clipboard_read
工作量·低

读取系统剪贴板文本，让 AI 可以直接分析复制的内容

使用 QApplication.clipboard().text() 获取剪贴板；超过 4000 字符时截断并提示。

示例：「帮我解释一下我复制的这段代码」→ 自动读取剪贴板传给 LLM
open_url
工作量·低

用系统默认浏览器打开指定 URL

调用 webbrowser.open(url)；URL 白名单校验（仅 http/https）防止恶意调用。

示例：「帮我打开 GitHub」「在浏览器里搜索这个错误」
calculate
工作量·低

安全执行数学表达式，避免 LLM 直接算数出错

用 Python ast 模块解析表达式树，白名单操作符（+−×÷幂次根号），不允许函数调用，完全安全。

示例：「帮我算一下 (1500 * 0.85) / 12」「√2 是多少」
run_command（白名单）
工作量·中

在严格白名单内执行只读 shell 命令，结果返回给 AI 分析

白名单仅包含 dir/ls、ping、ipconfig/ifconfig 等只读命令；执行超时 5 秒；输出截断 2000 字符。

示例：「当前目录有哪些文件？」「我的 IP 地址是多少？」

低工作量，可立即规划

3 项
每日问候与天气简报
工作量·低价值·高

每天首次启动时，宠物主动弹泡问候 + 显示今日天气

复用现有 WeatherTool；在 data/last_greet.txt 记录上次问候日期，判断「当天首次启动」后触发。根据时间段（早/中/晚）给出不同问候语，配合现有随机文案系统。

宠物状态卡悬浮窗
工作量·低价值·中

右键菜单增加「查看状态」，弹出迷你面板显示心情/饥饿/精力进度条

复用 MoodEngine.snapshot 数据；用 PyQt5 QProgressBar 渲染三个状态条，加上简短文字描述当前心情。完全不需要新美术资源，样式与现有互动面板保持一致。

基于时间的自动行为
工作量·低价值·中

根据时间自动触发行为：早上打招呼、下午提醒喝水、晚上说晚安

一个后台 QTimer 每分钟检查当前时间与上次触发时间，匹配规则后显示气泡。规则写在 config.json 中，用户可自定义时间段与文案。

中期功能

4 项，点击展开详情
多 LLM 后端支持
工作量·中价值·高

在配置界面支持选择 OpenAI / Ollama（本地）/ Anthropic Claude 作为 AI 后端

对 service.py 抽象 LLMProvider 接口；Ollama 使用 /api/chat 接口，完全本地无需 API Key。现有 tool calling 逻辑通过统一格式适配不同后端。

全局快捷键系统
工作量·中价值·高

全局热键呼出对话框（如 Ctrl+Shift+P），支持用户自定义

使用 keyboard 或 pynput 库注册全局钩子；快捷键配置写入 config.json；设置界面提供快捷键录制控件。

心情历史折线图
工作量·中价值·中

在心情面板增加「历史」标签，展示过去 7 天的心情/饥饿/精力折线图

MoodEngine 已有持久化；读取历史 JSON，用 PyQt5 QPainter 绘制简单折线（无需第三方图表库）。按天聚合均值，hover 显示具体数值。

Tool 插件热加载
工作量·中价值·高

工具目录支持「第三方 .py 插件」：放入 plugins/ 目录后自动注册，无需修改源码

在 tools/__init__.py 扫描 plugins/ 目录，动态 importlib.import_module 并调用 register()；BaseTool 接口不变。可以用 watchdog 监听目录变化实现热重载。
